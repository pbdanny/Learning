Document AI glossary

Processor
A deployed Document AI resource configured for one task: OCR, form parsing, invoice parsing, or custom extraction. Your API request targets a processor name, not merely a processor type.
Processor type
The capability family used when creating a processor, such as INVOICE_PROCESSOR, FORM_PARSER_PROCESSOR, or OCR_PROCESSOR.
Document
The canonical response object. It contains full text plus structured annotations such as pages, entities, tables, and layouts.
Entity
A semantic field returned by a specialized, form, or custom processor. An invoice total or supplier name is an entity; it is not automatically a validated accounting value.
Text anchor
A span pointing into Document.text. Preserve it to show where an extracted value came from and to make review/debugging possible.
Synchronous processing
A request for one document that returns a Document directly. Use it for interactive or small-document paths within the processor's limits.
Batch processing
An asynchronous operation for many documents, typically using Cloud Storage for input and output. Use it when the workflow is not interactive or documents exceed synchronous limits.
Normalization
A processor feature that can express certain values in typed forms, such as dates, money, and numbers. Validate the value against your own business rules anyway.
